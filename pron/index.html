この環境では音声認識が使えません。
  1. iPhoneの Safari でこのページを開く (アプリ内ブラウザやChromeでは動きません)
  2. 設定 → Siriと検索 → Siri をオン
  3. 設定 → 一般 → キーボード → 音声入力 をオン
  4. 初回は「音声認識を許可しますか」で 許可 をタップ
単語データを読み込めませんでした。電波の良い場所で開き直してください。
